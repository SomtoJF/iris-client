# iris-client

The Iris web app. Sign in, manage your profile and resumes, search jobs, apply, and track applications.

Talks to [iris-api](https://github.com/SomtoJF/iris-api).

## Run

```bash
cp sample.env .env
pnpm install
pnpm dev
```

App: [http://localhost:5173](http://localhost:5173)

The API should already be running on the URL in `.env`.
